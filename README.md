# Enterprise Active Directory Lab

## Project Overview

This repository documents my journey of learning and implementing Microsoft Active Directory in a virtual lab environment.

The project focuses on understanding Active Directory from the fundamentals to enterprise administration through hands-on practice and detailed documentation.


## Objectives

- Learn Windows Server Administration
- Install and Configure Active Directory Domain Services (AD DS)
- Configure DNS for Active Directory
- Design Organizational Units (OUs)
- Create and Manage Users and Groups
- Join Windows 11 Client to the Domain
- Configure and Test Group Policy Objects (GPOs)
- Configure File Server and Permissions
- Document troubleshooting steps


## Lab Environment

- VMware Workstation
- Windows Server 2022
- Windows 11
- Active Directory Domain Services
- DNS Server


## Learning Approach

Every topic in this repository includes:

- Theory
- Internal Working
- Practical Implementation
- Commands Used
- Screenshots
- Troubleshooting


## Disclaimer

This repository is created for educational purposes and hands-on learning.
