# Loopback Processing

## Purpose

Apply User Configuration based on the computer being used instead of the user's OU.

## Modes

Replace

The computer's User Configuration replaces the user's User Configuration.

Merge

The user's User Configuration is applied first, then the computer's User Configuration.

If there is a conflict, the computer's settings win.

## Common Uses

- Computer Labs
- Libraries
- Reception PCs
- Kiosks
- Shared Workstations
