# Project Goal

The goal of this project is to build a complete Active Directory lab from scratch while understanding every concept behind it.

Instead of only following installation steps, every configuration will be studied from both an administrative and technical perspective.

The project emphasizes:

- Understanding concepts before implementation
- Hands-on practice
- Proper documentation
- Troubleshooting skills

By the end of this project, I should be able to confidently deploy, configure, manage, and explain an enterprise Active Directory environment.
