# Organizational Units (OU)

## Objective

Create a logical structure to organize Active Directory objects.

## Why OUs?

Organizational Units help administrators organize users, computers, and groups logically. They also allow Group Policies and delegated administration to be applied to specific departments instead of the entire domain.

## OU Structure

- HR
- Finance
- IT
- Servers
- Workstations
- Security Groups

## Result

A basic enterprise-style OU hierarchy was created successfully.
