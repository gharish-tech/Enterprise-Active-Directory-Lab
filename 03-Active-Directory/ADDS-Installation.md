# Active Directory Domain Services Installation

## Objective

Install the Active Directory Domain Services (AD DS) role on Windows Server 2022.

## What is AD DS?

Active Directory Domain Services is a Windows Server role that enables centralized management of users, computers, groups, and authentication within a Windows domain.

Installing the role prepares the server for promotion to a Domain Controller.

## Result

The AD DS role was successfully installed. The server is now ready to be promoted to a Domain Controller.
